# 🥷 404 Ninja Slash - Interactive Error Page

An interactive, retro 8-bit styled 404 error page built with vanilla HTML5 Canvas and JavaScript. It features an animated pixel-art ninja slicing the 404 text with slow-motion dynamic time scaling, mouse-tracking eyes, and interactive slicing mechanics.

## ✨ Features

* **Pixel-Art Animation:** Frame-by-frame HTML5 Canvas animation loop.
* **Dynamic Slow-Motion Effect:** Matrix-style speed modulation (`timeScale`) as the ninja approaches the target.
* **Interactive Mouse Tracking:** The ninja's eyes dynamically follow the user's cursor or touch points.
* **Interactive Slicing Mechanics:** Users can click and drag to slice through the screen with custom particle spark effects.
* **Zero External Dependencies:** Built entirely using modern HTML5, CSS3, and native JavaScript.
